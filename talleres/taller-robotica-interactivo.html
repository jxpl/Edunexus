🤖 Desafío 1: Sensores y Ultrasonido

Estás programando un robot evasor de obstáculos usando un sensor ultrasónico (HC-SR04). ¿Qué componente del sensor emite la onda de alta frecuencia para medir la distancia?

¡Respuesta Correcta!

¡Excelente! El pin 'Trig' (Trigger) envía el pulso de ultrasonido, mientras que el pin 'Echo' recibe el rebote para calcular la distancia.

Inténtalo de nuevo

El pin 'Trig' es el que dispara la onda de ultrasonido. El pin 'Echo' solo recibe la respuesta.
